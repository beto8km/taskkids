🔧 Configurar Firebase

Cole aqui os dados do seu projeto Firebase. Faça isso só uma vez — todos os celulares vão compartilhar os mesmos dados.

Como pegar esses dados (5 minutos):

  1. Acesse console.firebase.google.com com sua conta Google
  2. Clique em "Criar um projeto" → nome: taskkids
  3. Dentro do projeto, clique em "Adicionar app" → ícone </> (Web)
  4. Dê um nome qualquer e clique em "Registrar app"
  5. Copie os valores de apiKey, projectId e appId
  6. No menu lateral: Criação → Firestore Database → Criar banco de dados → Modo de teste → Avançar
